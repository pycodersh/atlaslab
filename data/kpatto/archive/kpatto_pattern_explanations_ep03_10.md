# K-PATTO 패턴 설명 텍스트 EP03~10

---

## EP03 — 떡볶이 가게에서

### PATTERN 001: ~하고 싶어요
```
💡 How to use
Say what you WANT to do.

[verb stem] + 고 싶어요

먹고 싶어요. (I want to eat.)
해보고 싶어요. (I want to try it.)
Drop 다 from the verb, add 고 싶어요!
```

### PATTERN 002: ~할 수 있어요 / 없어요
```
💡 How to use
Say what you CAN or CANNOT do.

[verb stem] + ㄹ/을 수 있어요 → can
[verb stem] + ㄹ/을 수 없어요 → can't

매운 거 먹을 수 있어요? (Can you eat spicy food?)
젓가락 쓸 수 있어요. (I can use chopsticks.)
```

### PATTERN 003: ~이/가 아니에요
```
💡 How to use
Say what something is NOT.

[noun] + 이 아니에요 (ends in consonant)
[noun] + 가 아니에요 (ends in vowel)

이거 제 거 아니에요. (This isn't mine.)
저 학생 아니에요. (I'm not a student.)
```

### PATTERN 004: ~못해요
```
💡 How to use
Say you CAN'T do something (casual speech).

못 + [verb]

매운 거 못 먹어요. (I can't eat spicy food.)
Shorter and more natural than ~할 수 없어요!
```

### PATTERN 005: ~맞아요?
```
💡 How to use
Check if something is correct.

[noun/place] + 맞아요?

이게 떡볶이 맞아요? (Is this tteokbokki?)
여기 홍대 맞아요? (Is this Hongdae?)
Great for double-checking directions or orders!
```

## EP04 — 편의점에서

### PATTERN 001: ~해도 돼요?
```
💡 How to use
Ask for permission to do something.

[verb stem] + 아/어도 돼요?

사진 찍어도 돼요? (May I take a photo?)
여기서 먹어도 돼요? (Is it okay to eat here?)
Polite and safe to use anywhere!
```

### PATTERN 002: ~하면 안 돼요
```
💡 How to use
Say something is NOT allowed.

[verb stem] + 으면/면 안 돼요

여기서 피우면 안 돼요. (You can't smoke here.)
뛰면 안 돼요. (You can't run.)
Used for rules and prohibitions.
```

### PATTERN 003: ~는/은 어때요?
```
💡 How to use
Ask for an opinion or make a suggestion.

[noun] + 은/는 어때요?

이거는 어때요? (How about this one?)
이 맛은 어때요? (What do you think of this flavor?)
은 after consonant / 는 after vowel.
```

### PATTERN 004: ~로 할게요
```
💡 How to use
Say what you'll choose or go with.

[noun] + 로/으로 할게요

카드로 할게요. (I'll pay by card.)
이걸로 할게요. (I'll go with this one.)
로 after vowel / 으로 after consonant.
```

### PATTERN 005: ~얼마나 걸려요?
```
💡 How to use
Ask how long something takes.

[noun/action] + 얼마나 걸려요?

거기까지 얼마나 걸려요? (How long does it take to get there?)
배달 얼마나 걸려요? (How long does delivery take?)
```

## EP05 — 식당에서

### PATTERN 001: ~주실 수 있어요?
```
💡 How to use
Make a polite request — more formal than 주세요.

[action] + 주실 수 있어요?

천천히 말해주실 수 있어요? (Could you speak slowly?)
물 더 주실 수 있어요? (Could you bring more water?)
Use this when you want to be extra polite!
```

### PATTERN 002: ~추천해 주세요
```
💡 How to use
Ask for a recommendation.

[category] + 추천해 주세요

메뉴 추천해 주세요. (Please recommend a menu item.)
맛있는 거 추천해 주세요. (Please recommend something delicious.)
Works at restaurants, shops, anywhere!
```

### PATTERN 003: ~해 본 적 있어요?
```
💡 How to use
Ask if someone has ever done something.

[verb stem] + 아/어 본 적 있어요?

삼겹살 먹어 본 적 있어요? (Have you ever had samgyeopsal?)
한국 와 본 적 있어요? (Have you ever been to Korea?)
```

### PATTERN 004: ~어디서 살 수 있어요?
```
💡 How to use
Ask where you can buy something.

[noun] + 어디서 살 수 있어요?

이거 어디서 살 수 있어요? (Where can I buy this?)
김치 어디서 살 수 있어요? (Where can I buy kimchi?)
```

### PATTERN 005: ~맛있어요 / 맛없어요
```
💡 How to use
Express how food tastes.

[food] + 맛있어요 → delicious
[food] + 맛없어요 → not good

진짜 맛있어요! (It's really delicious!)
생각보다 맛없어요. (It's not as good as I expected.)
```

## EP06 — 노래방에서

### PATTERN 001: ~좋아해요 / 싫어해요
```
💡 How to use
Say what you like or dislike (ongoing preference).

[noun] + 좋아해요 → I like ~
[noun] + 싫어해요 → I don't like ~

케이팝 좋아해요. (I like K-pop.)
매운 거 싫어해요. (I don't like spicy food.)
Different from 좋아요 — 좋아해요 = ongoing habit!
```

### PATTERN 002: ~알아요?
```
💡 How to use
Ask if someone knows something.

[noun] + 알아요?

이 노래 알아요? (Do you know this song?)
BTS 알아요? (Do you know BTS?)
Simple and super useful in conversation!
```

### PATTERN 003: ~가르쳐 주세요
```
💡 How to use
Ask someone to teach you something.

[subject] + 가르쳐 주세요

이 노래 가르쳐 주세요. (Please teach me this song.)
한국어 가르쳐 주세요. (Please teach me Korean.)
```

### PATTERN 004: 같이 ~해도 돼요?
```
💡 How to use
Ask if you can do something TOGETHER.

같이 + [verb] + 해도 돼요?

같이 불러도 돼요? (Can we sing together?)
같이 가도 돼요? (Can I come with you?)
같이 = together — adds a friendly nuance!
```

### PATTERN 005: ~너무 좋아요!
```
💡 How to use
Say you LOVE something (stronger than 좋아요).

[noun] + 너무 좋아요!

이 노래 너무 좋아요! (I love this song so much!)
너무 = so much / very — amplifies the feeling!
```

## EP07 — 시장에서

### PATTERN 001: 조금만 더 주세요
```
💡 How to use
Ask for a little more of something.

조금만 더 + [noun] + 주세요
Or just: 조금만 더 주세요!

조금만 더 주세요. (A little more, please.)
조금만 = just a little / 더 = more
Great at markets and restaurants!
```

### PATTERN 002: ~깎아 주세요
```
💡 How to use
Ask for a discount — essential at markets!

좀 깎아 주세요. (Please give me a discount.)
조금만 깎아 주세요. (Just a little discount, please.)
깎다 = to cut/reduce. Works best at traditional markets!
```

### PATTERN 003: 같이 ~해요
```
💡 How to use
Suggest doing something together.

같이 + [verb] + 해요 / [verb ending]

같이 먹어요. (Let's eat together.)
같이 가요. (Let's go together.)
같이 = together — friendly and casual!
```

### PATTERN 004: ~신기해요!
```
💡 How to use
Express that something is interesting or unique.

[noun] + 신기해요!

이거 신기해요! (This is so interesting!)
한국 시장 신기해요! (Korean markets are so unique!)
신기하다 = to find something fascinating/novel.
```

### PATTERN 005: 다 해서 얼마예요?
```
💡 How to use
Ask the total price for everything.

다 해서 얼마예요?

다 해서 얼마예요? (How much is it all together?)
다 = all / 해서 = adding up to
Use when buying multiple items!
```

## EP08 — 뷰티숍에서

### PATTERN 001: 피부에 좋아요?
```
💡 How to use
Ask if something is good for your skin.

[product] + 피부에 좋아요?

이거 피부에 좋아요? (Is this good for skin?)
민감한 피부에 좋아요? (Is it good for sensitive skin?)
피부 = skin / 에 좋아요 = is good for ~
```

### PATTERN 002: ~써봤어요?
```
💡 How to use
Ask if someone has tried using something.

[product] + 써봤어요?

이 크림 써봤어요? (Have you tried this cream?)
마스크팩 써봤어요? (Have you tried sheet masks?)
써보다 = to try using something.
```

### PATTERN 003: 어떤 게 좋아요?
```
💡 How to use
Ask which option is better or recommended.

어떤 게 좋아요? (Which one is good?)
제 피부엔 어떤 게 좋아요? (Which is good for my skin?)
어떤 = which / 게 = thing (casual for 것이)
```

### PATTERN 004: ~선물하려고요
```
💡 How to use
Say you're planning to give something as a gift.

[person] + 한테 선물하려고요

친구한테 선물하려고요. (I'm planning to give it to my friend.)
엄마한테 선물하려고요. (I'm planning to give it to my mom.)
~하려고요 = planning to / intending to.
```

### PATTERN 005: 제 피부 타입에 맞는 거 추천해 주세요
```
💡 How to use
Ask for a recommendation suited to your skin type.

제 피부 타입에 맞는 거 추천해 주세요.
(Please recommend something for my skin type.)

맞는 거 = something that suits/fits
This full sentence works perfectly as-is!
```

## EP09 — 한강에서

### PATTERN 001: 같이 ~해요
```
💡 How to use
Invite someone to do something together.

같이 + [verb]해요!

같이 먹어요! (Let's eat together!)
같이 앉아요! (Let's sit together!)
같이 = together — warm and friendly tone!
```

### PATTERN 002: 날씨 좋다!
```
💡 How to use
Comment on great weather (casual expression).

날씨 좋다! (The weather is great!)
오늘 날씨 너무 좋다! (Today's weather is so nice!)
좋다 = casual form of 좋아요 — used with friends!
```

### PATTERN 003: 생각보다 ~
```
💡 How to use
Say something is better/different than expected.

생각보다 + [adjective/description]

생각보다 맛있어요. (It's more delicious than I expected.)
생각보다 넓어요. (It's bigger than I expected.)
생각보다 = more than I thought / better than expected.
```

### PATTERN 004: ~처음이에요
```
💡 How to use
Say it's your first time doing something.

[noun/experience] + 처음이에요

한강 피크닉 처음이에요. (It's my first Han River picnic.)
한국 치킨 처음이에요. (It's my first Korean fried chicken.)
처음 = first time — great for sharing new experiences!
```

### PATTERN 005: 이런 거 너무 좋아요
```
💡 How to use
Say you love this kind of thing or moment.

이런 거 너무 좋아요. (I love this kind of thing.)
이런 순간 너무 좋아요. (I love moments like this.)
이런 거 = this kind of thing — expresses genuine feeling!
```

## EP10 — 학교에서

### PATTERN 001: 저는 ~이에요/예요
```
💡 How to use
Introduce yourself — say who you ARE.

저는 + [name/identity] + 이에요/예요

저는 에마예요. (I'm Emma.)
저는 미국 사람이에요. (I'm American.)
저는 = I (polite) — always use in formal intro!
```

### PATTERN 002: ~에서 왔어요
```
💡 How to use
Say where you're from.

[country/city] + 에서 왔어요

미국에서 왔어요. (I'm from America.)
서울에서 왔어요? (Are you from Seoul?)
에서 = from / 왔어요 = came (past tense of 오다)
```

### PATTERN 003: ~전공이에요
```
💡 How to use
Say what your major is.

[major] + 전공이에요

경영학 전공이에요. (My major is business.)
뭐 전공이에요? (What's your major?)
전공 = major — essential for university life!
```

### PATTERN 004: 잘 부탁드려요
```
💡 How to use
A polite phrase for new relationships — hard to translate directly!

잘 부탁드려요. (Please take care of me. / Nice to meet you.)
앞으로 잘 부탁드려요. (I look forward to working with you.)
Always said at introductions — shows respect and humility!
```

### PATTERN 005: 한국어로 천천히 말해줄 수 있어요?
```
💡 How to use
Ask someone to speak Korean slowly for you.

한국어로 천천히 말해줄 수 있어요?
(Can you speak Korean slowly?)

천천히 = slowly / 말해줄 수 있어요 = can you speak?
This sentence will save you so many times!
```
