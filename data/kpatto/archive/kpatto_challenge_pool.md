# K-PATTO 챌린지 문제 풀 + Claude Code 지시문

## 챌린지 구조 지시사항

### 문제 구성 규칙
- 패턴 1개당 문제 3개 (객관식 2 + 단어조합 1)
- EP당 총 15문제 풀 (패턴 5개 × 3문제)
- 매 챌린지 출제: 5문제
  - 패턴당 객관식 1문제씩 랜덤 → 3문제
  - 전체 단어조합 풀에서 랜덤 2문제
  - 즉, 패턴 커버리지 보장 + 단어조합 2개 고정

### 문제 유형
- **객관식 (mc)**: 영어 문장 보고 한국어 4지선다
- **단어조합 (wb)**: 영어 문장 보고 한국어 단어 블록 조합해서 문장 완성

### 출제 로직 (코드 구현)
```
1. 패턴별로 객관식 문제 그룹화
2. 각 그룹에서 1문제 랜덤 선택 → 3문제
3. 전체 단어조합 풀에서 2문제 랜덤 선택
4. 총 5문제 셔플해서 출제
5. EP01 구조 그대로 유지, 데이터만 교체
```

## 데이터 구조 (코드 참고용)

```typescript
type QuestionType = 'mc' | 'wb'

interface MCQuestion {
  id: string
  type: 'mc'
  patternId: string
  episode: string
  prompt: string        // 영어 문장
  answer: string        // 정답 한국어
  distractors: string[] // 오답 3개
}

interface WBQuestion {
  id: string
  type: 'wb'
  patternId: string
  episode: string
  prompt: string        // 영어 문장
  answerBlocks: string[] // 정답 블록 순서
  extraBlocks: string[]  // 오답 블록
}

// 출제 로직
function generateChallenge(episode: string) {
  const mc = getMCByEpisode(episode)      // 패턴별 그룹
  const wb = getWBByEpisode(episode)      // 단어조합 풀

  // 패턴별 객관식 1문제씩 랜덤
  const mcQuestions = Object.values(groupByPattern(mc))
    .map(group => randomPick(group))       // 3문제

  // 단어조합 전체 풀에서 2문제 랜덤
  const wbQuestions = randomPick(wb, 2)   // 2문제

  return shuffle([...mcQuestions, ...wbQuestions]) // 총 5문제
}
```
