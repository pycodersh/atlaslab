# K-PATTO Pre-Course | 한글 마스터 커리큘럼 (최종)

> **목표**: 한글을 전혀 모르는 외국인이 10레슨을 통해 한글을 읽을 수 있게 된다
> **필수 구간**: 레슨 1~6 완료 시 스토리 1화 진입 가능
> **심화 구간**: 레슨 7~10은 스토리와 병행 학습 가능
> **플랫폼**: 모바일 세로 스크롤 / 인터랙티브 웹 컴포넌트

---

## 한글 교육 원칙

1. **소리 중심**: 글자 이름(기역, 니은)보다 소리(ㄱ=g/k, ㄴ=n)를 먼저
2. **결합 원리 중심**: 자음+모음=글자 구조를 체득하게
3. **의미 있는 단어**: 알파벳 나열이 아닌 실제 아는 단어로 연습
4. **음성 필수**: 모든 글자/단어에 원어민 음성 제공
5. **부담 없이**: 레슨당 5~7분, 핵심만

## LESSON 1 | 한글이란?
### "한글은 세계에서 가장 배우기 쉬운 문자예요"

**학습 목표**
- 한글이 어떤 문자인지 이해한다
- 자음 + 모음 = 글자 결합 원리를 시각적으로 이해한다
- 학습 동기를 높인다

**배울 내용**
- 한글의 역사 (세종대왕, 1443년 창제)
- 한글 = 자음 14개 + 모음 21개로 이루어진 과학적 문자
- 결합 구조 미리보기: ㄱ + ㅏ = 가
- 영어와 비교: 알파벳도 결합하면 단어가 되듯, 한글도 결합

**사용 글자/단어**
```
시각적 예시 (소리 없이 구조만):
ㄱ + ㅏ = 가
ㄴ + ㅏ = 나
ㄷ + ㅏ = 다
```

**화면 순서**
```
1. 인트로 카드
   "영어를 배울 때 알파벳을 먼저 배우죠?
    한국어는 한글을 먼저 배워요.
    한글은 하루면 읽을 수 있어요."

2. 세종대왕 일러스트 + 한 줄 설명
   "1443년, 세종대왕이 누구나 쉽게 읽고 쓸 수 있도록 만들었어요."

3. 한글 구조 애니메이션
   ㄱ (자음) + ㅏ (모음) → 합쳐지는 애니메이션 → 가
   "자음 + 모음 = 글자, 딱 이것만 알면 돼요."

4. 앞으로 배울 것 미리보기
   레슨 1~6 로드맵 카드 (진행 바 형태)

5. 마무리
   "준비됐어요? 모음부터 시작해요!"
```

**인터랙션/모션**
- ㄱ + ㅏ 결합 애니메이션: 두 글자가 슬라이드로 합쳐지며 가 완성
- 로드맵 카드: 레슨 아이콘 6개가 순서대로 등장
- 다음 버튼 탭 시 부드러운 페이드 전환

**완료 기준**
- 모든 카드를 끝까지 읽음
- "레슨 2 시작하기" 버튼 탭

## LESSON 2 | 기본 모음 10개
### "한글의 뼈대, 모음부터 시작해요"

**학습 목표**
- 기본 모음 10개의 소리를 듣고 따라 말할 수 있다
- 모음 모양과 소리를 연결할 수 있다
- 모음 단독으로 글자가 되는 원리를 이해한다 (ㅇ + 모음)

**배울 글자**
```
핵심 8개 (단모음):
ㅏ (a)   ㅓ (eo)  ㅗ (o)   ㅜ (u)
ㅡ (eu)  ㅣ (i)   ㅐ (e)   ㅔ (e)
```

> **교육 검수 노트**
> 단모음은 8개만 다룸 (ㅚ/ㅟ는 현대 구어에서 이중모음화 → 레슨 5로 이동)
> ㅐ와 ㅔ는 현대 한국어에서 사실상 같은 소리로 발음됨
> → 학습자에게 "둘 다 'e' 소리가 나요, 모양만 달라요"라고 안내
> ㅡ (eu)는 영어에 없는 소리 → 특별 강조, "입을 옆으로 벌리고 '으'" 설명 필요
> ㅓ (eo)도 영어에 없는 소리 → "입을 크게 벌리고 '어'" 설명 필요

**모음 단독 글자 원리**
```
모음만 쓸 때는 앞에 ㅇ(소리 없는 자음)을 붙임
ㅏ → 아  /  ㅓ → 어  /  ㅗ → 오  /  ㅜ → 우
ㅡ → 으  /  ㅣ → 이
```

**화면 순서**
```
1. 도입
   "모음은 소리의 핵심이에요.
    한글 모음은 하늘(·), 땅(ㅡ), 사람(ㅣ)을 본떠 만들었어요."

2. 모음 그룹 1 — 기본 4개 (ㅏ ㅓ ㅗ ㅜ)
   → 각각 탭하면 원어민 음성 재생 + 입 모양 힌트
   → ㅏ/ㅓ, ㅗ/ㅜ 쌍으로 비교 설명

3. 모음 그룹 2 — 나머지 4개 (ㅡ ㅣ ㅐ ㅔ)
   → ㅡ/ㅣ: 영어에 없는 소리 강조
   → ㅐ/ㅔ: "둘 다 'e' 소리, 모양만 달라요" 안내

4. ㅇ + 모음 결합 설명
   ㅏ → 아, ㅓ → 어 애니메이션

5. 읽기 연습 (3단어)
   아이 (child) / 우유 (milk) / 오이 (cucumber)
   → 탭하면 음성 재생

6. 퀴즈 5문제
   소리 들려주고 → 모음 고르기 (4지선다)
```

**인터랙션/모션**
- 모음 카드 탭 → 카드 플립 애니메이션 → 뒷면에 발음 힌트 + 음성
- 입 모양 아이콘: 단순 일러스트로 ㅡ, ㅓ 같은 어려운 소리 시각화
- 단어 탭 → 글자 하이라이트되며 음성 재생
- 퀴즈 정답 → 초록 체크 애니메이션 / 오답 → 살짝 흔들림

**완료 기준**
- 퀴즈 5문제 중 3문제 이상 정답

## LESSON 3 | 기본 자음 14개
### "자음은 소리의 시작이에요"

**학습 목표**
- 기본 자음 14개의 소리를 듣고 따라 말할 수 있다
- 자음을 3그룹으로 나눠 효율적으로 기억한다
- 영어 소리와 비교해서 이해한다

**배울 글자**
```
그룹 1 — 기본 소리 (평음) 9개
ㄱ (g/k)  ㄴ (n)   ㄷ (d/t)  ㄹ (r/l)  ㅁ (m)
ㅂ (b/p)  ㅅ (s)   ㅈ (j)    ㅇ (ng/없음)

그룹 2 — 거센 소리 (격음) 5개
ㅋ (k)   ㅌ (t)   ㅍ (p)   ㅊ (ch)   ㅎ (h)
```
> ※ 된소리(ㄲ ㄸ ㅃ ㅆ ㅉ)는 레슨 9에서만 다룸 — 이 레슨에서는 언급하지 않음

> **교육 검수 노트**
> ㄹ은 영어 r도 l도 아닌 한국어 고유음
> → "혀끝을 윗니 뒤에 살짝 대고 튕기는 소리" 로 설명
> → 단어 처음: r에 가까움 / 받침: l에 가까움 (지금은 소리만 듣고 따라하기)
> ㅇ은 단어 처음에 오면 소리 없음(레슨 2에서 이미 학습), 받침으로 오면 ng
> → 여기서는 "받침 ㅇ = ng" 만 추가 설명
> ㅈ은 영어 j와 비슷하지만 유성음화되지 않음
> → "영어 j보다 살짝 부드러운 ch 느낌" 으로 설명
> ㄱ/ㄷ/ㅂ은 단어 첫소리에서 부드럽게, 발음 위치별 변화는 레슨 8~9에서

**화면 순서**
```
1. 도입
   "자음은 14개예요. 영어 알파벳 26개보다 훨씬 적어요!"

2. 그룹 1 — 평음 9개 (순차 공개)
   한 번에 다 보여주지 않고 3개씩 나눠서 순서대로 등장
   탭하면 획순 애니메이션 + ㅏ와 결합 예시 (가/나/다/라/마/바/사/자/아)

3. 그룹 2 — 격음 5개
   "이 소리들은 숨을 강하게 내뱉어요 — 손 앞에 대면 바람이 느껴져요"
   카/타/파/차/하 로 예시, 평음과 비교 (ㄱ vs ㅋ)

4. 자음 이름 vs 소리
   "한국어에서는 자음 이름을 '기역, 니은'이라고 불러요.
    하지만 지금은 소리만 알면 충분해요."

5. 읽기 연습 (5단어)
   나비 (butterfly) / 바나나 / 가방 (bag) / 모자 (hat) / 사진 (photo)

6. 퀴즈 5문제
   소리 들려주고 → 자음 고르기
```

**인터랙션/모션**
- 자음 카드 탭 → 획순 드로잉 애니메이션 (붓이 그리듯)
- 획순 후 → 자동으로 ㅏ와 결합 → 음절 완성 애니메이션
- 그룹별 색상 구분 (평음: 파랑 / 격음: 주황)
- 퀴즈 정답/오답 애니메이션 레슨 2와 동일

**완료 기준**
- 퀴즈 5문제 중 4문제 이상 정답

## LESSON 4 | 자음 + 모음 결합
### "이제 글자를 만들어요"

**학습 목표**
- 자음 + 모음이 결합하는 두 가지 구조를 이해한다
- 임의의 자음+모음 조합을 보고 읽을 수 있다
- 실제 단어를 자음+모음 단위로 분해해서 읽을 수 있다

**배울 내용**
```
규칙 1 — 세로 모음 (모음이 세로로 긴 경우) → 자음이 왼쪽
ㄱ + ㅏ = 가  /  ㄴ + ㅓ = 너  /  ㅂ + ㅣ = 비
해당 모음: ㅏ ㅓ ㅣ ㅐ ㅔ

규칙 2 — 가로 모음 (모음이 가로로 긴 경우) → 자음이 위쪽
ㄱ + ㅗ = 고  /  ㄴ + ㅜ = 누  /  ㅂ + ㅡ = 브
해당 모음: ㅗ ㅜ ㅡ
```

> **교육 검수 노트**
> 핵심 원리: 모음의 생김새가 자음의 위치를 결정함
> 세로로 긴 모음(ㅏ ㅓ ㅣ ㅐ ㅔ) → 자음이 왼쪽
> 가로로 긴 모음(ㅗ ㅜ ㅡ) → 자음이 위쪽
> 학습자에게: "모음 모양을 보면 자음이 어디 갈지 알 수 있어요"
> 이 원리 하나로 모든 글자 배치가 설명됨 — 용어보다 시각적으로 보여주는 것이 핵심

**화면 순서**
```
1. 도입
   "이제 자음과 모음을 합쳐볼 거예요.
    딱 두 가지 규칙만 알면 모든 글자를 만들 수 있어요."

2. 규칙 1 시각화 — 세로 모음
   ㅏ 모양 강조 (세로로 긴 선) → ㄱ이 왼쪽으로 이동 → 가 완성 애니메이션
   나/너/비 등 여러 조합으로 반복

3. 규칙 2 시각화 — 가로 모음
   ㅗ 모양 강조 (가로로 긴 선) → ㄱ이 위쪽으로 이동 → 고 완성 애니메이션
   누/브 등 여러 조합으로 반복

4. 직접 만들어보기 (인터랙티브)
   자음 카드 + 모음 카드 중 각 1개 선택
   → 탭하면 결합된 글자 + 음성 재생

5. 단어 읽기 연습 (5단어)
   고기 (meat) / 도시 (city) / 커피 (coffee) / 기차 (train) / 버스 (bus)
   → 글자 하나씩 하이라이트되며 읽기
   ※ 나비/바나나는 레슨 3에서 이미 사용 → 새 단어로 교체

6. 퀴즈 5문제
   자음+모음 조합 보여주고 → 맞는 소리 고르기
```

**인터랙션/모션**
- 결합 애니메이션: 자음 카드와 모음 카드가 물리적으로 합쳐지는 모션
- 직접 만들기: 자음/모음 카드 선택 → 중앙에서 결합 → 바운스 효과
- 단어 읽기: 글자 하나씩 순서대로 하이라이트 + 음성 동기화

**완료 기준**
- 퀴즈 5문제 중 4문제 이상 정답
- 직접 만들기 3회 이상 시도

## LESSON 5 | 이중모음 11개
### "모음이 합쳐지면 새로운 소리가 나요"

**학습 목표**
- 이중모음 11개의 소리를 듣고 따라 말할 수 있다
- 이중모음이 기본 모음의 조합임을 이해한다
- 이중모음이 포함된 단어를 읽을 수 있다

**배울 글자**
```
핵심 이중모음 9개 (필수):
ㅑ (ya)   ㅕ (yeo)  ㅛ (yo)   ㅠ (yu)
ㅘ (wa)   ㅝ (wo)   ㅢ (ui)
ㅚ (oe→we) ㅟ (wi→we)  ← 레슨 2에서 이동, 현대 발음은 이중모음

참고 이중모음 4개:
ㅒ (yae)  ㅖ (ye)   ㅙ (wae)  ㅞ (we)
→ 현대 구어에서 드물거나 ㅔ와 동일하게 발음됨
```

> **교육 검수 노트**
> ㅒ는 ㅣ+ㅐ 결합 / ㅖ는 ㅣ+ㅔ 결합 — 분해 표기는 학습자에게 혼란을 주므로 생략
> → ㅒ(yae), ㅖ(ye) 로만 소리 표기, 현대 발음은 ㅔ와 거의 동일함을 안내
> ㅚ/ㅟ는 레슨 2에서 단모음으로 소개 안 했으므로 여기서 처음 등장
> → "현대 한국어에서는 이중모음으로 발음해요" 안내
> ㅢ (ui)는 위치에 따라 발음이 달라짐
> → 단어 첫 글자: 의사 [의사] / 조사 ~의: [에]로 발음 / 그 외: [이]로 발음
> → 지금은 "의사(doctor)" 단어로만 소개, 상세 규칙은 레슨 8에서
> ㅘ = ㅗ+ㅏ / ㅝ = ㅜ+ㅓ 분해는 시각적으로 보여줘도 좋음 (직관적)

**화면 순서**
```
1. 도입
   "모음끼리 합쳐지면 새로운 소리가 나요.
    어렵게 생각하지 말고, 두 소리를 빠르게 이어서 읽으면 돼요."

2. 핵심 이중모음 9개 (ㅑ ㅕ ㅛ ㅠ ㅘ ㅝ ㅢ ㅚ ㅟ)
   ㅘ/ㅝ는 기본 모음 분해 표시 (ㅘ = ㅗ+ㅏ, ㅝ = ㅜ+ㅓ)
   ㅚ/ㅟ: "현대 한국어에서는 이중모음으로 발음해요" 안내
   ㅢ: "의사처럼 단어 첫 글자에서는 [의]로 읽어요" 안내

3. 참고 이중모음 4개 (ㅒ ㅖ ㅙ ㅞ)
   "이런 것들도 있어요 — 현대 한국어에서는 ㅔ와 거의 같은 소리예요"

4. 단어 읽기 연습 (6단어)
   야구 (baseball) / 여자 (woman) / 요리 (cooking)
   유리 (glass) / 와이파이 (Wi-Fi) / 의사 (doctor)

5. 퀴즈 5문제
   이중모음 소리 듣고 → 맞는 모음 고르기
```

**인터랙션/모션**
- 이중모음 카드: 두 기본 모음이 합쳐지는 애니메이션 후 이중모음 등장
- 핵심/참고 탭 구분: 탭 버튼으로 전환
- 단어 카드: 이중모음 글자에 색상 강조 표시

**완료 기준**
- 퀴즈 5문제 중 4문제 이상 정답

## LESSON 6 | 받침
### "글자 아래에 자음이 오면 받침이에요"

**학습 목표**
- 받침이 있는 글자 구조를 이해한다
- 기본 받침 7개의 소리를 구분할 수 있다
- 받침이 있는 단어를 읽을 수 있다

**배울 내용**
```
받침 구조:
  자음
  모음
  받침 ← 여기

기본 받침 7개 (대표음):
ㄱ받침 → [k] 소리  예: 국 (soup), 먹 (eat)
ㄴ받침 → [n] 소리  예: 한 (Korean), 눈 (eye/snow)
ㄹ받침 → [l] 소리  예: 말 (speech), 일 (work)
ㅁ받침 → [m] 소리  예: 봄 (spring), 감 (persimmon)
ㅂ받침 → [p] 소리  예: 밥 (rice), 입 (mouth)
ㅅ받침 → [t] 소리  예: 맛 (taste), 옷 (clothes)
ㅇ받침 → [ng] 소리 예: 강 (river), 방 (room)
```
> ※ ㄷ받침은 실생활 단어에서 드물어 제외 / ㅅ받침(맛, 옷)이 훨씬 자주 등장

> **교육 검수 노트**
> 이 레슨의 목표는 완벽한 발음이 아니라 "받침이 있는 글자 구조를 읽을 수 있는 것"
> 받침 7개 대표음만 알면 읽기 가능 — 정확한 발음은 음성 들으며 자연스럽게 습득
> ㄱ받침 자리에는 ㄱ/ㅋ/ㄲ 모두 올 수 있으나 지금은 대표음만 안내
> ㅅ받침 자리에도 ㅅ/ㄾ/ㅈ/ㅊ 등 여러 글자가 오지만 지금은 ㅅ만 다룸
> 겹받침(닭, 삶 등)은 이 레슨에서 다루지 않음 → 레슨 10에서 맛보기

**화면 순서**
```
1. 도입
   "한글 글자는 최대 3층 구조예요.
    자음 / 모음 / 받침
    받침은 3층에 오는 자음이에요."

2. 구조 시각화
   가 → 갈 (받침 ㄹ 추가되는 애니메이션)
   나 → 남 (받침 ㅁ 추가되는 애니메이션)

3. 받침 7개 카드
   각 카드: 받침 글자 + 소리 + 예시 단어
   ㄱ → 국 (soup) / ㄴ → 한국 / ㄹ → 말 (speech)
   ㅁ → 봄 (spring) / ㅂ → 밥 (rice) / ㅅ → 맛 (taste) / ㅇ → 강 (river)

4. 단어 읽기 연습 (7단어)
   한국 / 밥 / 물 / 맛 / 강남 / 봄 / 일
   → 받침 글자 색상 강조
   ※ "맛있다"는 연음+경음화 복합 적용 단어라 이 단계에서 제외
   ※ "한국"은 연음 미학습 단계이므로 "지금은 글자 구조만 봐요" 안내 추가

5. 전체 구조 복습
   자음 + 모음 + 받침 = 완성된 글자 도식

6. 퀴즈 7문제
   단어 보여주고 → 받침 소리 고르기 (4지선다)

7. 🎉 레슨 6 완료 화면
   "이제 한글을 읽을 수 있어요!
    스토리 1화를 시작할 준비가 됐어요!"
   [ 지금 바로 스토리 1화 시작하기 ]
   [ 레슨 7 계속하기 ]
```

**인터랙션/모션**
- 받침 추가 애니메이션: 2층 글자 아래로 받침이 내려오며 결합
- 받침 카드 탭 → 받침 위치 강조 (테두리 빛나는 효과) + 음성
- 단어 읽기: 받침 글자만 색상 다르게 하이라이트
- 레슨 6 완료 화면: 축하 파티클 애니메이션 + 스토리 1화 입장 버튼

**완료 기준**
- 퀴즈 7문제 중 6문제 이상 정답 (스토리 진입 전 마지막 관문)
- 완료 화면 도달

## LESSON 8 | 발음 규칙 1 — 연음
### "글자대로 읽으면 안 될 때가 있어요"

**학습 목표**
- 연음 현상(받침이 다음 모음으로 넘어가는 현상)을 이해한다
- 연음이 적용된 단어를 올바르게 읽을 수 있다

**배울 내용**
```
연음 규칙:
받침 있는 글자 + 모음으로 시작하는 글자가 만나면
→ 받침이 다음 글자의 첫소리로 넘어감

예시:
한국어  표기: 한-국-어  /  발음: [한구거]  han-gu-geo
먹어요  표기: 먹-어-요  /  발음: [머거요]  meo-geo-yo
있어요  표기: 있-어-요  /  발음: [이써요]  i-sseo-yo
밥을    표기: 밥-을      /  발음: [바블]    ba-beul
```

> **교육 검수 노트**
> 연음은 한국어 말소리의 가장 기본적인 규칙
> 이것만 알아도 자연스러운 발음에 훨씬 가까워짐
> 스토리 대사에서 계속 나오기 때문에 일찍 배울수록 좋음

**화면 순서**
```
1. 도입
   "한국어는 쓰는 것과 읽는 것이 조금 달라요.
    받침 뒤에 모음이 오면 받침이 넘어가요."

2. 연음 애니메이션
   한 국 어 → ㄱ 받침이 '어'로 넘어가는 화살표 애니메이션
   한 구 거 로 변환되는 과정

3. 예시 5개 연습
   각각 "글자 표기 → 실제 발음" 비교 카드

4. 듣고 따라하기 (5문장)
   스토리 1화 대사에서 발췌

5. 퀴즈 4문제
   단어 보여주고 → 실제 발음 고르기
```

**인터랙션/모션**
- 연음 화살표: 받침에서 다음 글자로 이어지는 애니메이션
- 표기/발음 비교: 좌우 카드 슬라이드로 전환
- 따라하기: 음성 재생 후 마이크 버튼 (선택적 구현)

**완료 기준**
- 퀴즈 4문제 중 3문제 이상 정답

## LESSON 9 | 발음 규칙 2 — 격음화·ㅎ 약화
### "ㅎ이 옆 소리를 바꿔요"

**학습 목표**
- 격음화 (ㄱ+ㅎ → [ㅋ] 등) 현상을 이해한다
- ㅎ 약화/탈락 현상을 이해한다
- 경음화는 레슨 10에서 간단히 다룸

**배울 내용**
```
격음화 (거센소리되기):
ㄱ + ㅎ / ㅎ + ㄱ → [ㅋ]  예: 축하 → [추카]
ㄷ + ㅎ / ㅎ + ㄷ → [ㅌ]  예: 좋다 → [조타]
ㅂ + ㅎ / ㅎ + ㅂ → [ㅍ]  예: 입학 → [이팍]
ㅈ + ㅎ / ㅎ + ㅈ → [ㅊ]  예: 좋지 → [조치]

ㅎ 약화/탈락:
모음과 모음 사이 ㅎ → 소리가 약해지거나 사라짐
예: 좋아요 → [조아요]
    많아요 → [마나요]
```
> ※ 경음화(된소리되기)는 레슨 10으로 이동 — 레슨 9는 격음화+ㅎ 관련으로 통일
> ※ "전화 → [저놔]" 예시 제거 — ㄴ+ㅎ 현상은 다른 규칙이라 혼란 유발

> **교육 검수 노트**
> 격음화와 ㅎ탈락은 모두 ㅎ과 관련된 현상이므로 함께 배우면 자연스러움
> 이 레슨의 목표는 "왜 들리는 것과 쓰인 것이 다른가" 인식 — 암기 불필요
> 스토리 대사에서 계속 등장하므로 자연스럽게 익히도록 유도

**화면 순서**
```
1. 도입
   "ㅎ은 옆에 오는 자음을 바꾸는 특별한 소리예요.
    외울 필요 없어요, 들으면서 익히면 돼요."

2. 격음화 4가지 예시 (애니메이션)
   ㅎ + 자음 / 자음 + ㅎ → 합쳐져서 거센소리 완성

3. ㅎ 약화/탈락 2가지 예시
   모음 사이 ㅎ이 사라지는 애니메이션

4. 실제 대화에서 듣기 (스토리 발췌 3문장)
5. 퀴즈 4문제 (소리 듣고 맞는 표기 고르기)
```

**인터랙션/모션**
- 글자 변환 애니메이션: ㄱ+ㅎ → ㅋ 합체 모션
- 오디오 파형 시각화 (음성 재생 시)

**완료 기준**
- 퀴즈 4문제 중 3문제 이상 정답
