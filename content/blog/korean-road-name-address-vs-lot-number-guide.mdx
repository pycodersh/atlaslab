Korea uses two address systems: the newer road-name address (도로명주소), based on streets and building numbers, and the older lot-number address (지번주소), based on land plots. Both still appear, and pasting either into a Korean map app is the easiest way to find a place.

<KeyTakeaways>

- **Road-name address:** the official system; road name plus building number
- **Lot-number address:** the older system, still common in conversation and some listings
- **Order:** big to small: province or city, district, road, building, then unit
- **Avoid:** typing Korean addresses into Google Maps; use Naver Map or KakaoMap

</KeyTakeaways>

## Road-name vs lot-number

| | Road-name (도로명주소) | Lot-number (지번주소) |
| :--- | :--- | :--- |
| **Based on** | Streets and building numbers | Neighborhoods (dong) and land plot numbers |
| **Example** | Seoul, Jongno-gu, Sejong-daero 175 | Seoul, Jongno-gu, Sejongno 1-68 |
| **Status** | Official since 2014 | Still used informally |
| **Easy to navigate?** | Yes; numbers follow the street | Harder; plot numbers can jump around |

## Reading the parts

| Part | Korean | Example |
| :--- | :--- | :--- |
| **City or province** | 시 · 도 | 서울특별시 (Seoul) |
| **District** | 구 · 군 | 마포구 (Mapo-gu) |
| **Road** | 로 · 길 | 월드컵북로 4길 (World Cup-buk-ro 4-gil) |
| **Building number** | 건물번호 | 12 |
| **Building (apartment) block** | 동 | 101동 (building 101) |
| **Unit** | 호 | 1203호 (unit 1203: 12th floor, room 3) |
| **Postal code** | 우편번호 | 5 digits |

<Callout type="tip" title="로 vs 길">
A 로 (*ro*) is a major road; a 길 (*gil*) is a smaller street branching off it, numbered by side street. Odd building numbers are on one side of the road and even numbers on the other.
</Callout>

## Why two systems exist

For most of the 20th century, Korean addresses followed land plots inside each neighborhood (dong), so neighboring buildings could have unrelated numbers. In 2014 the government made the street-based road-name system official to make navigation easier for drivers, delivery workers and visitors. Many Koreans still mention neighborhood names in conversation, though, and older documents and some listings keep the lot-number address.

| Situation | Which format you'll usually see |
| :--- | :--- |
| **Official documents, deliveries** | Road-name address |
| **Older property listings** | Lot-number address, sometimes both |
| **Asking for directions** | Neighborhood names and landmarks |
| **Map apps** | Both, searchable either way |

When someone gives you directions in person, they'll often skip the address entirely and use a subway exit number and a landmark, such as "exit 3, next to the convenience store." Save both the address and the nearest exit for any place you're meeting.

## Searching and writing addresses

| Task | Tip |
| :--- | :--- |
| **Finding a place** | Paste the Korean address into Naver Map or KakaoMap |
| **Taxis** | Show the Korean address on your phone |
| **Deliveries and parcels** | Include building (동) and unit (호) numbers |
| **English address** | Write small to big: unit, building, road, district, city |
| **Converting formats** | The official address search site shows both formats |

## Frequently Asked Questions

**Which address system should I use?**
The road-name address is official and best for deliveries. The lot-number address still works in map searches.

**What do 동 and 호 mean?**
In an apartment complex, 동 is the building number and 호 is the unit number. 1203호 usually means the 12th floor, unit 3.

**How do I write a Korean address in English?**
Go from small to large: unit, building, road and number, district, city, postal code.

**Why can't Google Maps find my address?**
Google's Korean address data is limited. Paste the address into Naver Map or KakaoMap instead.
