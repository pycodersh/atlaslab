Sooner or later, not being able to type Korean holds you back: you want to look up a word you heard, search a song title, or reply in a language exchange app. A Korean keyboard takes about two minutes to add, and its layout is worth understanding, because it was designed rather than inherited.

## Setting it up

| Device | Where to add it | Switch with |
|---|---|---|
| iPhone | Settings → General → Keyboard → Keyboards → Add New Keyboard → Korean | the globe key |
| Android (Gboard) | Gboard settings → Languages → Add keyboard → Korean | the globe key |
| Windows | Settings → Time & Language → Language & region → Add a language → Korean | right Alt or the 한/영 key |
| Mac | System Settings → Keyboard → Text Input → Edit → + → Korean → 2-Set Korean | globe key or Caps Lock |

Menu names vary a little between phone makers and system versions, but the Korean keyboard sits under language or keyboard settings everywhere.

## Which layout?

Phones offer two:

- **2-Set (두벌식):** a QWERTY grid with Hangul on the keys, the same layout as a computer keyboard. Start here.
- **10 Key (천지인):** builds every vowel from three marks, ㆍ ㅡ ㅣ (ㅏ is ㅣ then ㆍ). Many Koreans like it for one-handed typing, but it takes practice.

On Windows, the **right Ctrl** key turns the word you just typed into Chinese characters. You'll almost never need it, and you'll hit it by accident at least once.

## How the 2-Set layout works

**Consonants are on the left hand, vowels on the right.** Korean syllables alternate consonant and vowel, so your hands alternate too.

| Row | Left hand (consonants) | Right hand (vowels) |
|---|---|---|
| top | ㅂ ㅈ ㄷ ㄱ ㅅ | ㅛ ㅕ ㅑ ㅐ ㅔ |
| home | ㅁ ㄴ ㅇ ㄹ ㅎ | ㅗ ㅓ ㅏ ㅣ |
| bottom | ㅋ ㅌ ㅊ ㅍ | ㅠ ㅜ ㅡ |

**Shift** gives the [tense consonants](/blog/en/k-patto/korean-consonants-19-basic-sounds): Shift + ㅂ = ㅃ, and likewise ㅉ ㄸ ㄲ ㅆ. It also turns ㅐ and ㅔ into ㅒ and ㅖ. That's the entire extra layer.

## You don't build the blocks

Type letters in order and the keyboard assembles the blocks: type ㄱ, then ㅏ, then ㅁ, and you'll see ㄱ → 가 → 감.

The one surprise: if the next letter is a vowel, the keyboard moves the last consonant into a new block. Type 감 and then ㅏ, and you get **가마**. That's correct, and it matches how Korean syllables work. The [syllable structure guide](/blog/en/k-patto/korean-syllable-structure-why-every-block-matters) explains why.

<Callout type="tip" title="A first exercise">

Type your own name in Hangul. It makes you think about which Korean sounds are closest to yours, and it's short enough to finish. Then search for a food, a place or a song in Korean: you already know roughly what the results should say, so it doubles as reading practice.

</Callout>
